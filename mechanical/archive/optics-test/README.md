# Optics test rig (superseded, kept for reference)

This rig belonged to roadmap WP 0.2: a real-size hexagon chamber lit by cut SK6812 RGBW strip, with depth rings, tilted LED carriers and a film clamp. **WP 0.2 was dropped on 2026-11-16**, when the user decided not to buy LED strip. The optics test now runs on the rev A edge boards in the real panel, using the diffuser risers in `mechanical/panel/` (decision 0012).

The rig predates the 13.5 mm boards, the frame and the clamped film. **Don't print or update it.** It's kept only as a reference for the depth, aim and film-count ideas.
